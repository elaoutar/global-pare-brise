====================================================
DOSSIER LOGO - GLOBAL PARE-BRISE
====================================================

Pour afficher votre logo sur l'application et tous les documents officiels :

1. Déposez votre fichier logo ici dans ce dossier ("public").
2. Nommez le fichier : logo.png
   (Exemple de chemin : GlobalePareBrise/public/logo.png)

Format recommandé : 
- Format : PNG (avec fond transparent de préférence) ou JPG / WebP
- Dimensions idéales : 400px à 800px de large (hauteur proportionnelle)

Dès que "logo.png" est placé ici, il apparaîtra automatiquement :
- Sur la barre latérale de l'application (Navigation)
- Sur la page de connexion
- Sur toutes les Factures (A4 & PDF)
- Sur tous les Bons de Livraison (BL)
- Sur tous les Devis Clients
- Sur tous les Bons de Sortie de stock
- Sur les Bons de Commande Fournisseur
- Sur les Bordereaux de Remise de Chèques/Effets
- Sur les Rapports et Bordereaux d'Assurance

Si vous utilisez un autre nom ou format (ex: logo.jpg), vous pouvez 
le changer dans le fichier `src/lib/data.ts` à la ligne :
   logoUrl: '/logo.jpg',
